1GitHub 账号

读取的是 GitHub 公开资料（头像 / 昵称 / 公开仓库数），仅用于标识评委身份，不会获取你的仓库权限，也不会保存到任何服务器。

2直接体验

3D 校园地图 → 250 栋建筑、182 个地标，单指平移、双指缩放 理宝信息库 → 问一句：取快递在哪 / 绩点怎么算 / 校园卡 源码仓库 → 单文件实现，WebGL 渲染器与问答引擎全部可读 作品首页 → 完整的新生动线：入学准备 → 导航 → 办事

3建议的 90 秒体验路径

  1. 点「3D 校园地图」→ 允许定位，起点自动变成"我的位置"
  2. 右上「路线导航」→ 点「去取快递」→ 看 302 米 / 4 分钟的路线
  3. 点地图上的「申通快递·东苑」，详情里有取件分区：400 号以上右侧货架
  4. 返回首页 → 底部「理宝信息库」→ 顶部输入"取快递""绩点""校园卡"
  5. 在问答结果里点「在地图上定位」，会直接跳到地图并预选导航终点

4关于「接入 API」

问答引擎
本地意图匹配，58 条知识条目，响应 <10 毫秒，断网可用，不把校内政策问题发往云端。
场景数据
scene.json 描述建筑轮廓、高度、屋顶参数、标签与路网，修改数据重新构建即可，无需重做模型。
云端通道
预留了大模型问答接口位（开通云端服务后可切换，支持按用户限次）。当前版本默认走本地引擎，保证离线与响应速度。
身份说明
本页的 GitHub 身份为公开资料标识，非 OAuth 授权登录；如需真正的 GitHub 授权（读取私有仓库等），需部署一个换取 token 的后端服务。
