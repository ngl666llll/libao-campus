两种方式，选一种即可。

【方式 A：网页上传，不用命令行（推荐，2 分钟）】
1. 打开 https://github.com/new
2. Repository name 填：libao-campus
3. 选 Public → 点 Create repository
4. 页面点「uploading an existing file」
5. 把本文件夹里的 index.html、README.md、.nojekyll 三个文件拖进去
   （.nojekyll 是隐藏文件，Windows 资源管理器要先勾「显示隐藏的项目」；
     漏了它也能用，只是 GitHub 会多跑一次 Jekyll）
6. 点 Commit changes
7. 进仓库 Settings → 左侧 Pages → Source 选「Deploy from a branch」
   → Branch 选 main、目录选 / (root) → Save
8. 等 1–2 分钟，刷新 Pages 页面，顶部会出现：
   https://你的用户名.github.io/libao-campus/
9. 手机打开这个地址验证：能转 3D、能规划路线、定位可用

【方式 B：命令行推送（仓库已 init 好，只差 remote）】
cd 发布-github
git remote add origin https://github.com/你的用户名/libao-campus.git
git branch -M main
git push -u origin main
然后按方式 A 的第 7、8 步开启 Pages。

【说明】
· 仓库名可以改，Pages 地址跟着变：https://用户名.github.io/仓库名/
· 页面是单文件，放在子路径下也能正常运行（没有绝对路径依赖）
· 更新作品：替换 index.html 后 commit，Pages 一两分钟自动生效
· 国内访问 github.io 有时偏慢，评委如果打不开，可同时保留平台链接
