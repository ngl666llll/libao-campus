# 理宝 · 成都理工大学 3D 数字校园助手

一个单文件 Web 应用：把整座校园做成可交互的 3D 模型，把散落在二十多个系统里的入学信息整理成可执行的答案。

**在线访问**：部署 GitHub Pages 后，地址为 `https://<你的用户名>.github.io/<仓库名>/`

## 这是什么

新生入学的第一个月，真正消耗时间的往往不是学习，而是"找不到、查不到、看不懂"。

- **找不到** → 自研 WebGL 渲染的 3D 校园，250 栋建筑、178 个地标、421 条道路、5 条水道
- **怎么走** → 基于路网图的最短路径规划，多套方案 + 步行时间估算，支持 GPS 起点
- **看不懂** → 理宝信息库：成绩绩点、转专业、选课、补考重修、奖助学金、推免、医保、缴费、宿舍生活

## 功能

| 模块 | 说明 |
|---|---|
| 3D 数字校园 | 自研 WebGL 渲染器，不依赖 Three.js 运行时；程序化几何 + 图集批处理；昼夜光照 |
| 路径规划 | 路网无向图 + Dijkstra；多方案；GPS 实时定位起点 |
| 原位编辑 | 浏览器内点选建筑/校门/标签改字段，实时重建，导出 scene.json |
| 理宝信息库 | 常用入口 10 个、小程序教程 3 篇、成理速查 17 条、新生学堂 9 篇 |
| 移动端 | 底部可拖动抽屉、单指平移、双指缩放旋转 |

## 使用

电脑或手机浏览器直接打开即可，无需安装、无后端依赖。

> 手机定位需要 HTTPS（GitHub Pages 默认满足）；本地 `file://` 打开时浏览器禁止定位，导航起点需手动选择。

## 技术要点

- 单文件封装：HTML + 内联 JS/CSS + base64 内嵌地图 iframe
- 坐标：GCJ-02 纠偏 + 单应配准
- 跨端：Blob URL → data URL → srcdoc 三级降级，兼容 iOS `file://`
- 性能：移动端 54–60 fps；画质自适应带迟滞；路线图层 30fps 节流

## 数据来源

OpenStreetMap（ODbL）与成都理工大学官网、教务处、学生处、研究生院、计划财务处、网络与信息化处的公开资料。

## 许可

代码仅用于学习与校园服务；地图数据遵循 ODbL；校名、校徽等标识归成都理工大学所有。
